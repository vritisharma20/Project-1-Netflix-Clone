# 🎬 Netflix Clone

A Netflix-inspired front-end website created using **HTML5 and CSS3**. This project recreates the look and feel of Netflix with a modern design and an attractive user interface.

## ✨ Features

- 🎥 Netflix-inspired user interface
- 🎨 Attractive design and CSS styling
- 🖼️ Movie and streaming-inspired layout
- 💻 Clean HTML structure
- 📱 Responsive design *(if implemented)*

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/vritisharma20/Project-1-Netflix-Clone.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

## 🎯 Project Objective

The main objective of this project is to practice front-end web development, improve HTML and CSS skills, and understand how to create an attractive website layout inspired by a popular streaming platform.
